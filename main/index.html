PIPELINE

From motifs to a reversible sequence.

01 / EXISTING REPRESENTATION

GraphBPE → SAFE

Use the existing molecular partition and SAFE serialization. Keep only exact-boundary records. Do not run GraphBPE again during text tokenization.

02 / FIRST CODEC

Rank whole fragments

Count literal TRAIN fragments, labels included. Keep M=2,136 base entries; add the most frequent K−M complete fragments. Misses use base tokens.

03 / DIAGNOSE MISSES

Labels create variants

C4c1cccs1 and C8c1cccs1 cannot share a complete-string ID. A shared substring can reuse c1cccs1 while retaining each original label.

04 / HYBRID CODEC

Learn within fragments

Train BPE on base-token sequences inside individual TRAIN fragments. No merges across dots; identical payloads share IDs. Keep exactly K model entries.

05 / SELECT & ENCODE

Use validation

Compare 25%, 50%, 75% whole-fragment shares of K−M. Complete-fragment hits emit one ID; misses use BPE substrings. Dots stay separate.

06 / RECONSTRUCT

IDs → SAFE → molecule

Concatenate vocabulary byte payloads. Restore the complete SAFE before parsing the molecule. No per-molecule edge table or original SAFE side table.

Evidence, dictionary fingerprints and reproduction

All three graphs were replayed from genuine saved records with the current GraphBPE+SAFE pipeline. Source atom groups, proposed/accepted cuts and SAFE strings matched the original records; paired cross-fragment labels were checked against accepted cuts. No intermediate GraphBPE merge history is invented.

Both frozen codecs were reloaded at 16k and 32k. Every output ID was resolved in its actual dictionary; complete hits were checked to remain single tokens. Concatenating the payloads reproduced the SAFE text exactly. The real SAFE decoder was then called on that restored text and the canonical isomeric molecule matched the source in all 12 combinations. The browser independently rechecks ID-to-text reconstruction using only the used vocabulary entries.

The dictionary excerpt contains shared token definitions, not molecule-specific connectivity. The source SAFE and graph metadata are used for comparison and visualization only. Sample selection and the 5,663 changed-boundary records

SAFE changes the proposed GraphBPE boundaries in 5,663 of the 49,992 successful records. These cases are excluded from the fixed-boundary comparison. The current implementation restricts certain cuts to preserve stereochemistry; omitted cuts can involve double, single, aromatic and triple bonds.

Of the 44,329 boundary-preserving records, CHEMBL1213498 lacks a successful BRICS result, leaving 44,328 shared molecules. Across all 44,329, DemoDiff and fixed GraphBPE counts also agree record by record: 372,957 tokens, mean 8.413386.

For CHEMBL55653, skipping a double-bond cut changes four GraphBPE motifs into three SAFE fragments while preserving molecular reconstruction. Boundary change is distinct from decoding failure.

The full original-SMILES DemoDiff run encodes 49,998 of 50,000 records, with two SMILES parsing errors and zero successfully encoded rows reporting unknown nodes.
