ChEMBL 35：NPE + SAFE 基序变体与跨分子共享分析
日期：2026-11-12；仅分析 899,836 条 SAFE/NPE 边界一致且严格还原通过的分子。
数据来自原始有序前 100 万条有效、去重分子。没有混入边界变化记录，没有重新训练 NPE。

1. 基本统计
片段出现次数：7,603,382；平均片段数：8.449742。
训练词表含 3,000 个 NPE ID；此子集实际使用 2,852 个 ID。
合并规范化图结构相同的键后，实际观察到 2,740 种基序。下述每基序变体统计以该图结构键分组，而非直接按 ID 分组。
带跨片段连接标号的片段出现 7,548,218 次，涉及 898,772 个分子。

2. 不同定义下的变体类型数（全量 / 至少一个跨片段连接）
基序图结构键：2,740 / 2,726
原始完整 SAFE 片段字符串：430,956 / 429,934
编号归一化后的字符串模式：88,578 / 87,556
忽略全局编号的规范化局部连接图：55,056 / 54,034

原始字符串保留实际编号、原子遍历顺序及所有符号。编号归一化分别标记内部闭环与跨片段连接，但仍保留字符串遍历顺序。
局部连接图在完整 SAFE 图上识别片段，将每个外部连接替换为无编号的虚拟邻接原子，再输出规范化 SMILES；保留连接位置、键类型及可表达的局部立体/原子属性。
局部连接图会丢弃外部邻居身份与全分子配对关系，只用于诊断统计，不能单独无损还原整个分子。
不同局部连接图不一定只差连接位置，也可能存在键型、局部立体、电荷或同位素差异。

4. 随机两个不同分子的共享概率
在同一 899,836 分子总体中均匀抽取 1,000,000 对不同分子；每对内部不允许同一个分子，跨试验允许重复。固定种子 20261112，各方法使用同一组分子对。
下表仅把含跨片段连接的片段计为共享；没有此类片段的分子仍保留在分母中。括号为蒙特卡洛抽样的 95% Wilson 区间，不是对整个 ChEMBL 的泛化区间。
基序图结构键：共享至少一个 = 20.8304% (20.7509%–20.9101%)；仅多原子片段 = 5.7811%。
原始完整 SAFE 片段字符串：共享至少一个 = 2.4837% (2.4534%–2.5144%)；仅多原子片段 = 0.2919%。
编号归一化后的字符串模式：共享至少一个 = 12.1286% (12.0648%–12.1927%)；仅多原子片段 = 1.9324%。
忽略全局编号的规范化局部连接图：共享至少一个 = 12.1485% (12.0846%–12.2127%)；仅多原子片段 = 2.5648%。

多原子指至少两个真实原子，不含用于诊断的虚拟连接原子。NPE 包含单原子基元，因此必须单独展示这一限制下的结果。
对某个具体词条 f，若有 df 个不同分子包含它，随机两个不同分子同时包含它的精确概率为 df*(df-1)/(N*(N-1))。
把这个概率对所有词条相加得到的是共享不同词条数的期望，不能当作共享至少一个词条的概率。

高频带标号多原子片段：
CO4：12,116 个分子；单分子出现率 1.3465%；随机两分子同时包含它 0.01813%；例子 CHEMBL444748, CHEMBL501964, CHEMBL500769。
c15ccccc1：10,853 个分子；单分子出现率 1.2061%；随机两分子同时包含它 0.01455%；例子 CHEMBL441934, CHEMBL441576, CHEMBL500798。

c16ccccc1：9,723 个分子；单分子出现率 1.0805%；随机两分子同时包含它 0.01167%；例子 CHEMBL155784, CHEMBL265564, CHEMBL498862。

一个词条在数据集中被复用，与两个随机分子恰好共享它，是不同的问题；总体复用与低分子对匹配概率并不矛盾。

6. 解释与限制
具体编号和书写顺序显著放大了词表，降低跨分子的完全字符串匹配概率。不能把所有字符串变体都解释为不同化学基序。
但是直接删除编号不能构成新的无损编码：仍需保留全分子的连接配对信息。局部编号归一化只是一项诊断，不是已经实现的替代 tokenizer。
此分析复用了 NPE 训练语料，是描述性统计，不是独立测试集覆盖率，也不是生成模型性能。
当前总片段类型数包含 1,022 种无跨片段连接的字符串；带标号类型数已单独列出。
基序图键继承原 NPE 的单原子键语义；单原子电荷、同位素等信息仍在 SAFE 字符串/局部连接图中。
局部连接图总数为 55,056，而基序-局部连接图对数为 55,058；存在局部图归入多个原 NPE 兼容图键的情况，使配对计数多出 2，不能混用这两个计数。原始完整 SAFE 字符串没有这种父基序歧义。
全量核验：原始输入筛选后的索引和次序、每种片段出现次数、保存的 NPE ID 计数与规范化基序计数均匹配；899,836 条记录无提取错误、无基序多重集不一致。
