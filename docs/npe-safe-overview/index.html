Dataset and counting conventions

The NPE vocabulary was trained on 50,000 ChEMBL 35 molecules (3,000 node entries including 300 frequent ring systems). The SAFE comparison retained 45,402 molecules whose fragment atom sets exactly matched the NPE partition. The complete dictionary contains 25,655 observed pairs under 2,666 node IDs. The frequency ≥ 3 dictionary stores 9,625 complete entries and 8,256 fallback scaffolds. OPEN and CLOSE parameters belong to the fragment position. These are observed-corpus results.
