Why 3,000 vocabulary entries, 2,852 observed IDs, and 2,740 analysis groups?

The trained vocabulary still has 3,000 original NPE IDs. Of these, 2,852 occur in this selected cohort. For the variant census only, each observed motif SMILES is parsed and written as canonical isomeric SMILES; equal keys are grouped into 2,740 canonical analysis groups. This does not retrain, shrink or renumber the NPE vocabulary.

There are 2,631 groups containing one observed ID, 106 groups containing two IDs, and 3 groups containing three IDs: 2,631 + 106 × 2 + 3 × 3 = 2,852 IDs, but 2,631 + 106 + 3 = 2,740 groups.

What is normalized, and what information remains?

Exact labelled SAFE strings: retain the literal digits, atom order and all syntax. Label-normalized patterns: rename internal ring pairs and external connection labels separately, while retaining lexical traversal. Local connection graphs: identify fragments in the complete molecular graph, replace each external neighbour with an unnumbered dummy attachment atom, and write canonical SMILES. These retain attachment positions, bond types and locally represented atom/stereo attributes, while discarding global pairing numbers and outside-neighbour identities.

Local connection graphs are diagnostic keys, not a lossless replacement encoding. Different variants can also reflect charge, isotope or stereochemistry. The original NPE single-atom keys inherit upstream element-only semantics. There are 55,056 distinct local connection graphs but 55,058 motif–connection-graph pairs because some local graphs occur under more than one NPE-compatible parent key.

Reuse is not the same as random-pair overlap. Of the 429,934 labelled string types, 241,986 occur in at least two molecules and 187,948 occur in only one. Two random molecules can still have a low chance of sharing exactly the same numbered string.

For one fragment type occurring in df different molecules, the exact probability that both members of a random distinct pair contain it is df × (df − 1) / [N × (N − 1)]. Summing across types gives the expected number of shared distinct types, not the probability of sharing at least one. The latter is estimated using sampled molecule pairs. Identical local labels do not require the same external neighbouring motif.

Analysis procedure and validation
SELECT records WHERE pipeline_ok AND strict_roundtrip_ok
                     AND SAFE_partition == saved_NPE_partition
FOR each selected molecule:
    parse the COMPLETE SAFE string and track each dot-delimited fragment
    extract motif keys; verify their multiset against saved NPE IDs
    collect exact strings, label-normalized patterns and local connection graphs
    count each type once per molecule for document-frequency statistics
GROUP motif keys by canonical isomeric SMILES for diagnostic variant counts
SAMPLE 1,000,000 uniform pairs of DISTINCT molecules (fixed seed)
COMPARE whether each pair shares at least one qualifying type

All 899,836 selected indices and original fragment frequencies were independently checked against the saved outputs. Saved NPE-ID counts agree with canonical-group occurrence counts; no extraction errors or motif-multiset mismatches occurred. Ring-label reuse, fragment order, attachment positions, bond types, charge, isotope and local stereo behavior were tested. This analysis does not rerun NPE merges or learn a new vocabulary.

Actual total trained vocabulary: 3,000. Observed IDs: 2,852. Canonical analysis groups: 2,740. The grouping operation is separate from the tokenizer and is not a vocabulary-size optimization.

Sample selection and the 5,663 changed-boundary records

SAFE changes the proposed GraphBPE boundaries in 5,663 of the 49,992 successful records. These cases are excluded from the fixed-boundary comparison. The current implementation restricts certain cuts to preserve stereochemistry; omitted cuts can involve double, single, aromatic and triple bonds.

Of the 44,329 boundary-preserving records, CHEMBL1213498 lacks a successful BRICS result, leaving 44,328 shared molecules. Across all 44,329, DemoDiff and fixed GraphBPE counts also agree record by record: 372,957 tokens, mean 8.413386.

For CHEMBL55653, skipping a double-bond cut changes four GraphBPE motifs into three SAFE fragments while preserving molecular reconstruction. Boundary change is distinct from decoding failure.

The full original-SMILES DemoDiff run encodes 49,998 of 50,000 records, with two SMILES parsing errors and zero successfully encoded rows reporting unknown nodes.
